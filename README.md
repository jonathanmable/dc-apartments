# DC studio and one-bedroom tracker

The page: https://jonathanmable.github.io/dc-apartments/

Listed studios, junior and full one-bedrooms across 25 apartment buildings in Washington DC, read from each
building's own website three times a day: price, lease length, deals, fees, floor-plan features and price history.

`index.html` is generated after each check; nothing here is edited by hand.

Not affiliated with any building. Prices are the buildings' published prices.
